## Before every release

Ship calmly. A short checklist catches the small things that erode trust.

### Content

- [x] Read every screen out loud once.
- [x] Confirm empty states have a friendly sentence.
- [ ] Check that no placeholder text survived.

### Experience

- [x] App opens offline without a spinner.
- [x] Typing feels instant on a large note.
- [ ] Test the first-run flow on a clean profile.

### Access

- [ ] Verify keyboard navigation end to end.
- [ ] Confirm color contrast on every surface.
- [ ] Make sure focus is always visible.

> If a step is skipped, write down why. A checklist is a conversation, not a cage.
